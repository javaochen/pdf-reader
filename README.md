# PDF 阅读器（reader）

一个基于 **PySide6 + PyMuPDF** 的本地 PDF 阅读器，支持无损截取、书签导航与自动去白边渲染。

本目录是**可独立发布**的完整包：整个 `pdf_reader/` 文件夹复制到任意机器即可运行，不含任何本机专属绝对路径。

## 功能特性

- **无损截取（循环模式）**：`Ctrl+S` 进入截取模式后一直保持，可连续截取多张；每截完一次自动清空分割线并立即开始下一次，**只有再次按 `Ctrl+S` 才退出**
- 无损截取：只渲染要截取的区域（PyMuPDF clip），**分辨率按原图光学分辨率封顶**——扫描件绝不会被插值放大（实测最大省 17× 像素），结果复制到剪贴板
- 自动裁剪渲染（默认关闭，`Ctrl+Shift+R` 开关）：按页面级内容框切除四周白边，含**扫描噪点过滤**与**自适应背景阈值**（灰底扫描件也能生效），显示与截取共用同一套坐标映射
- 阅读姿态：**适合页面 / 适合宽度 / 原始大小**（`Ctrl+0` / `Ctrl+1` / `Ctrl+2`），放大后**按住左键拖拽平移**，**双击**在"放大"与"适合宽度"之间切换
- **后台预取**相邻页：连续翻页实测 0.7~1.0 ms/页（未预取时 90~160 ms）
- 书签：左侧书目面板、前/后书签跳转（↑/↓）、书签导出为 Markdown / 无序列表
- 阅读进度：自动记录最后阅读页码，下次打开自动恢复；落盘做防抖，不再是每翻一页写一次
- 命令面板、快速切换 PDF、跳页、缩放、遮挡模式

> 截取模式刻意只做**两条横线 + 跨页拼接 + 原生分辨率无损输出**，与 PixPin 之类外部截图工具互补；
> 任意矩形框选交给外部工具，这里专做外部工具做不到的事。

## 性能与实现要点

| 机制 | 说明 |
|---|---|
| 内容框缓存 | 每页用约 50 万像素的低倍探测算出内容框（页面坐标）并缓存；显示、适应页面缩放、无损截取共用同一份，未显示过的页也能按需算出 |
| 适应页面 | 由内容尺寸闭式求解缩放，一次渲染到位（旧实现"渲染→量尺寸→再修正"每次翻页要 3 次整页栅格化） |
| 截取 | 只渲染目标区域（PyMuPDF clip）；跨页截取的中转页按需算内容框，不再依赖"该页被显示过" |
| 内容框检测 | 灰度按 256 行分块 + 行列投影，峰值临时量 7.6MB 而非整图 104MB；不做降采样；行/列内容占比阈值滤掉扫描墨点；背景阈值按纸面底色自适应（灰底扫描件才可能真正去白边） |
| 截取分辨率 | 目标 300 DPI，但按该页内嵌图的像素/点比例封顶（并留 1.5 px/pt 下限）；扫描件页面框常按 72 DPI 由像素尺寸建立，固定 300 DPI 等于插值放大 4.17 倍 |
| 后台预取 | 显示完当前页就把前后各一页交给 worker 线程渲染（QImage 可跨线程，QPixmap 回主线程；MuPDF 访问用锁串行化），缓存键按目标页自己的缩放计算 |
| 视图模式 | 适合页面 / 适合宽度 / 手动；大页面扫描件主要靠"适合宽度 + 拖拽平移" |
| 页面缓存 | 条目数 + 总字节数双重上限（默认 256MB），截取产生的高分辨率位图不进缓存 |
| 防抖 | 滚轮缩放、窗口尺寸变化合并为一次渲染；阅读进度落盘合并为一次写入 |
| 上限保护 | 单次跨页截取最多 50 页、输出最多 2 亿像素，超限直接提示而不是拼出 GB 级位图 |

### 实测对比（同一台机器，改动前后同文档、同页、同条带）

测试文档为库里最大的一本：973 MB、1780 页、单页 2559×2135 pt（300 DPI 整页 = 95 MPx = 362 MB 位图）。

| 场景 | 优化前 | 优化后 |
|---|---|---|
| 单页条带截取（200 显示像素高） | 1126 ms，缓存残留 362 MB，RSS +540 MB | **429 ms**，缓存 0 MB，RSS +7 MB |
| 跨页截取（自动裁剪开启） | 1936 ms 后 `AttributeError` **崩溃** | **2432 ms 正常输出** 10663×20164 |
| 该文档翻页（fit + 自动裁剪） | 中位 116.7 ms/页，最大 176.9 ms | 中位 **105.1 ms/页**，最大 **109.8 ms** |
| 文本型 A4 文档翻页（fit + 自动裁剪） | 33.1 ms/页 | **15.4 ms/页** |
| A4 文档 1.6× 翻页（自动裁剪） | 53.2 ms/页 | **18.5 ms/页** |
| 300 DPI 整图内容框检测 | 132~204 ms | 104 ms（整图）/ **10.6 ms**（实际用的低倍探测图） |
| Ctrl+滚轮连续 10 档缩放 | 609~911 ms，10 次栅格化 | 事件处理 0 ms，防抖后 **1 次**栅格化 |
| 每翻一页的进度写盘 | 每次全量重写 JSON（3.5~4.2 ms） | 防抖 500 ms 合并一次 |

面向数学书（全扫描件）的第二轮实测，取自库里的真实书籍：

| 场景 | 优化前 | 优化后 |
|---|---|---|
| 条带截取·拓扑学（3171×4204pt，原生 1.0 px/pt） | 13213×7856 = 104 MPx / 786 ms | **4757×2829 = 13 MPx / 297 ms** |
| 整页截取·拓扑学 | 231 MPx **被上限拒绝** | 30 MPx **可行** |
| 条带截取·谢惠民 | 7300×4739 / 338 ms | **2628×1707 / 99 ms** |
| 条带截取·Boas（原生正好 4.17 px/pt） | 2064×1351 / 134 ms | 2064×1351 / **25 ms**（尺寸不变，仍更快） |
| 连续翻页·微积分学教程 | 91.9 ms/页 | **0.75 ms/页** |
| 连续翻页·拓扑学 | 161.2 ms/页 | **0.95 ms/页** |
| 连续翻页·数学建模 | 151.7 ms/页 | **0.72 ms/页** |
| 去白边·数学建模（采样页） | 0% | **10%**（墨点过滤后恢复） |

可用环境变量：

- `PDF_READER_LOG=DEBUG`：输出被捕获异常的细节（默认只输出 warning 以上）
- `PDF_READER_PAGE_CACHE_MAX_BYTES` 等常量可在 `reader.py` 顶部调整

## 环境要求

- Windows / macOS / Linux，Python 3.9+
- 依赖见 `requirements.txt`：`PySide6`、`PyMuPDF`、`numpy`

## 安装与运行

```bash
cd pdf_reader
pip install -r requirements.txt
python reader.py          # 或 Windows 下双击 run.bat
```

## 配置

所有配置项可选，优先级：**`reader_config.json` > 环境变量 > 默认值**。

```bash
copy reader_config.example.json reader_config.json    # Windows
```

| 键 | 环境变量 | 默认值 | 说明 |
|---|---|---|---|
| `pdf_root_dir` | `PDF_READER_PDF_ROOT_DIR` | 系统「下载」文件夹 | 启动时扫描/打开的 PDF 目录 |
| `state_dir` | `PDF_READER_STATE_DIR` | 同 `pdf_root_dir` | 阅读进度、最近打开记录的存放目录 |
| `initial_pdf_keyword` | `PDF_READER_INITIAL_PDF_KEYWORD` | 空 | 启动时按文件名关键字自动打开 |
| `initial_page` | `PDF_READER_INITIAL_PAGE` | `1` | 无历史记录时的起始页 |

**默认目录是运行时算出来的**，仓库里不含任何机器路径：Windows 先读注册表里系统认定的
「下载」文件夹（被用户在资源管理器里"移动位置"过也能找到），拿不到再依次退回
`~/Downloads` → `~/Documents` → 用户主目录。因此把这个包拷到别人机器上，它会落到**那个人自己**的下载目录。

进度文件：`.pdf_reader_history.json`、`.pdf_reader_recent.json`（位于 `state_dir`）。
默认 `state_dir` 与 `pdf_root_dir` 相同（即写进下载目录）；想放到别处就在配置里指定 `state_dir`。

## 截取模式（循环）

1. 按 `Ctrl+S` 进入截取模式（鼠标移动显示绿色预览线）
2. 回车确定**起始线**（红线），再次回车确定**结束线**（蓝线）→ 立即无损截取并复制到剪贴板
3. 分割线自动清空，可直接开始下一次截取；跨页截取（起始线与结束线在不同页）会自动纵向拼接
4. 按 `Esc` 只撤销分割线；**再次按 `Ctrl+S` 退出截取模式**
5. 输出分辨率：目标 300 DPI，但**不超过该页原图的光学分辨率**（扫描件不被插值放大）；跨页时取各页中的最小值。上限：单次最多 50 页、2 亿像素
6. 跳页（`Ctrl+I`）后模式保持有效：覆盖层会自动拿回键盘焦点，换页会清掉上一页残留的预览线，
   并且"回车确认"是窗口级快捷键，即使焦点被对话框拿走也照常生效

## 测试

无头运行，不需要显示器（自动使用 Qt `offscreen` 平台）。测试把 PDF 目录与状态目录
指向包内临时目录，不会扫描或写入用户的真实下载目录：

```bash
python tests/test_crop_loop.py         # 截取模式循环 + 跳页后仍可用（34 项）
python tests/test_capture_autocrop.py  # 截取/自动裁剪/缓存/防抖/上限（29 项）
python tests/test_math_reading.py      # 原生分辨率/抗噪阈值/预取/视图模式（20 项）
python tests/test_nav.py               # 书签相对导航（12 例）
```

关键不变量（回归测试覆盖）：clip 局部渲染与"整页渲染再裁剪"逐像素一致、
分块投影内容框与旧实现完全一致、自适应阈值只在灰底页收紧（纯白页结果不变）、
抗噪不会误伤正文、截取分辨率不超过原生且估算与渲染用同一缩放（不会误拦）、
冷页翻页栅格化 ≤2 次、截取不写入页面缓存、滚轮缩放只在防抖后渲染一次、
预取结果在缓存清空后不回填、适合宽度铺满视口、拖拽平移改变滚动位置。

## 打包发布

```bash
pip install pyinstaller
pyinstaller --noconfirm --windowed --name PDF阅读器 --icon assets/reader.ico ^
  --add-data "assets/reader.ico;assets" reader.py
```

打包后 `dist/PDF阅读器/` 即为可分发产物；`reader_config.json` 放在可执行文件同级目录即可生效。图标缺失时程序自动回退到 Qt 默认图标，不影响运行。

## 从上层 `launcher.py` 启动

上级目录的 `launcher.py` 已把本包登记为目标脚本（`pdf_reader/reader.py`），可在其中统一查看、暂停、重启。
