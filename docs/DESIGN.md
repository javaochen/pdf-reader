## 定位与取舍

场景是**啃扫描版数学书**（实测库里 12 本数学书全部无文本层、0 字/页，所以文本搜索/复制/OCR 类功能
在这些书上没有意义）。由此确定三件事：

1. **截取只做横线**（两条水平线 + 整行宽度）。矩形框选交给 PixPin 这类外部工具，
   内置模式专做它们做不到的：原生分辨率无损输出、跨页拼接、不受屏幕缩放/DPI 影响。
2. **阅读姿态以"适合宽度 + 平移"为主**。这些书的页面框常按 72 DPI 从扫描像素尺寸建立
   （例如 3171×4204 pt），fit 缩放只有 0.19，整页适配后根本看不清字。
3. **不能靠文本层定位**，因此能力集中在目录书签、页码与图像质量上。

## 代码结构

单文件 `reader.py`（约 2600 行），按职责自上而下分块：

| 区块 | 内容 |
|---|---|
| 配置层 | `load_config` / `_cfg` / `default_downloads_dir`：配置优先级与默认目录解析（无机器路径） |
| 图像算法 | `rgb_to_gray`、`content_row_col_hits`、`find_content_bbox_arr`、`estimate_background_level`、`adaptive_white_threshold`、`qimage_to_rgb_array`、`safe_crop_box` |
| 持久化 | `HistoryStore`（最后页码）、`RecentStore`（最近打开）：脏标记 + 防抖落盘 + 损坏文件可见报错 |
| 对话框 | `ShortcutListDialog`、`HelpDialog`、`BookmarkCopyDialog`、`QuickSwitchDialog`、`JumpPageDialog`、`CommandDialog` |
| 界面部件 | `BookmarkPanel`、`CropOverlay`（截取/遮挡覆盖层）、`PdfViewer`（渲染 + 缓存 + 截取）、`MainWindow`（快捷键/命令注册、状态落盘） |
| 后台任务 | `_PrefetchTask`（QRunnable，只产出 QImage，QPixmap 回主线程） |

关键约定：

- **内容框（去白边）只有一个来源**：`PdfViewer._content_box_pt()` 用低倍探测算出、以页面坐标缓存，
  显示、fit 缩放、无损截取共用；标记状态则只有 `CropOverlay` 一份（viewer 侧是 property 代理）。
- **每页可以按需算内容框**，不依赖"该页被显示过"。
- **后台预取的缓存键必须按目标页自己的缩放算**，否则键对不上、预取白做。

## 实现要点

| 机制 | 说明 |
|---|---|
| 内容框缓存 | 每页用约 50 万像素的低倍探测算出内容框（页面坐标）并缓存；显示、适应页面缩放、无损截取共用同一份，未显示过的页也能按需算出 |
| 适应页面 | 由内容尺寸闭式求解缩放，一次渲染到位（旧实现"渲染→量尺寸→再修正"每次翻页要 3 次整页栅格化） |
| 截取 | 只渲染目标区域（PyMuPDF clip）；跨页截取的中转页按需算内容框 |
| 内容框检测 | 灰度按 256 行分块 + 行列投影，峰值临时量 7.6 MB 而非整图 104 MB；不做降采样（实测 min 池化为了不漏细线要遍历全图，比精确计算更慢）；行/列内容占比阈值滤掉扫描墨点；背景阈值按纸面底色自适应（灰底扫描件才可能真正去白边） |
| 截取分辨率 | 目标 300 DPI，但按该页内嵌图的像素/点比例封顶（留 1.5 px/pt 下限）。扫描件页面框常按 72 DPI 由像素尺寸建立，固定 300 DPI 等于插值放大 4.17 倍 |
| 后台预取 | 显示完当前页就把前后各一页交给 worker 线程渲染（QImage 可跨线程，QPixmap 回主线程；MuPDF 访问用锁串行化） |
| 视图模式 | 适合页面 / 适合宽度 / 手动；页面大于视口时把标签最小尺寸抬到页面尺寸，滚动条范围才正确（见"已知限制"） |
| 页面缓存 | 条目数 + 总字节数双重上限（默认 256 MB），截取产生的高分辨率位图不进缓存 |
| 防抖 | 滚轮缩放、窗口尺寸变化合并为一次渲染；阅读进度落盘合并为一次写入 |
| 上限保护 | 单次跨页截取最多 50 页、输出最多 2 亿像素，超限直接提示而不是拼出 GB 级位图 |

## 实测数据

同一台机器，改动前后**同文档、同页、同条带**对比。

测试文档为库里最大的一本：973 MB、1780 页、单页 2559×2135 pt（300 DPI 整页 = 95 MPx = 362 MB 位图）。

| 场景 | 优化前 | 优化后 |
|---|---|---|
| 单页条带截取（200 显示像素高） | 1126 ms，缓存残留 362 MB，RSS +540 MB | **429 ms**，缓存 0 MB，RSS +7 MB |
| 跨页截取（自动裁剪开启） | 1936 ms 后 `AttributeError` **崩溃** | **2432 ms 正常输出** 10663×20164 |
| 该文档翻页（fit + 自动裁剪） | 中位 116.7 ms/页，最大 176.9 ms | 中位 **105.1 ms/页**，最大 **109.8 ms** |
| 文本型 A4 文档翻页（fit + 自动裁剪） | 33.1 ms/页 | **15.4 ms/页** |
| A4 文档 1.6× 翻页（自动裁剪） | 53.2 ms/页 | **18.5 ms/页** |
| 300 DPI 整图内容框检测 | 132~204 ms | 104 ms（整图）/ **10.6 ms**（实际用的低倍探测图） |
| `Ctrl`+滚轮连续 10 档缩放 | 609~911 ms，10 次栅格化 | 事件处理 0 ms，防抖后 **1 次**栅格化 |
| 每翻一页的进度写盘 | 每次全量重写 JSON（3.5~4.2 ms） | 防抖 500 ms 合并一次 |

第二轮，取自库里真实数学书（全扫描件）：

| 场景 | 优化前 | 优化后 |
|---|---|---|
| 条带截取·拓扑学（3171×4204pt，原生 1.0 px/pt） | 13213×7856 = 104 MPx / 786 ms | **4757×2829 = 13 MPx / 297 ms** |
| 整页截取·拓扑学 | 231 MPx **被上限拒绝** | 30 MPx **可行** |
| 条带截取·谢惠民 | 7300×4739 / 338 ms | **2628×1707 / 99 ms** |
| 条带截取·Boas（原生正好 4.17 px/pt） | 2064×1351 / 134 ms | 2064×1351 / **25 ms**（尺寸不变，仍更快） |
| 连续翻页·微积分学教程 | 91.9 ms/页 | **0.75 ms/页** |
| 连续翻页·拓扑学 | 161.2 ms/页 | **0.95 ms/页** |
| 连续翻页·数学建模 | 151.7 ms/页 | **0.72 ms/页** |
| 去白边·数学建模（采样页） | 0% | **10%**（墨点过滤后恢复） |

## 测试

四套无头回归测试，**不需要显示器**（自动用 Qt `offscreen` 平台），共 99 项。
测试会把 PDF 目录与状态目录指向包内临时目录，不会扫描或写入用户的真实下载目录。

```bash
python tests/test_crop_loop.py         # 截取模式循环 + 跳页后仍可用（34 项）
python tests/test_capture_autocrop.py  # 截取/自动裁剪/缓存/防抖/上限（29 项）
python tests/test_math_reading.py      # 原生分辨率/抗噪阈值/预取/视图模式（24 项）
python tests/test_nav.py               # 书签相对导航（12 例）
```

建议**逐套顺序执行**而不是并发跑：`test_capture_autocrop` 会做 300 DPI 级别的图像比对，
峰值内存约 300 MB；`test_math_reading` 会构造大页面样例（约 280 MB）。

覆盖的关键不变量：

- clip 局部渲染与"整页渲染再裁剪"**逐像素一致**（要求边界落在像素网格上）
- 分块投影内容框与旧实现**逐位一致**；自适应阈值只在灰底页收紧（纯白页结果不变）；抗噪不误伤正文
- 截取分辨率不超过原生，且**估算与渲染用同一缩放**（不会误拦合法截取）
- 冷页翻页栅格化 ≤2 次；截取不写入页面缓存；滚轮缩放只在防抖后渲染一次
- 预取结果在缓存清空后不回填；回到已渲染页不额外栅格化
- 适合宽度铺满视口；**标签长到页面尺寸、可滚动范围覆盖整页、滚到底页面底部可达**；非法标记不会让绘制崩溃
- 跳页后覆盖层重新拿到键盘焦点；换页清空残留预览线；焦点在别处时回车仍能确认分割线

## 打包发布

```bash
pip install pyinstaller
pyinstaller --noconfirm --windowed --name PDF阅读器 --icon assets/reader.ico ^
  --add-data "assets/reader.ico;assets" reader.py
```

打包后 `dist/PDF阅读器/` 即为可分发产物；`reader_config.json` 放在可执行文件同级目录即可生效。
图标缺失时自动回退到 Qt 默认图标，不影响运行。

## 重新生成 README 截图

```bash
python tools/make_screenshots.py        # 输出到 docs/screenshots/
```

脚本会现场生成一本原创排版的样例书，用**系统真实中文字体**渲染页面，再截图真实界面：

- **不能用 `QT_QPA_PLATFORM=offscreen`**：该平台拿不到系统中文字体，界面文字会渲染成方框；
  脚本改用系统默认平台 + `WA_DontShowOnScreen`，字体正常且窗口不上屏（不会打扰你）
- 样例书页面用 Qt 画成图片再嵌进 PDF，比 PyMuPDF 内置宋体的字距自然，也更像真实扫描件

## 已知限制与可做的改进

- `Ctrl+O`（快速切换）与 `Ctrl+0`（适合页面）在字体里容易看混，可考虑换键位
- `MainWindow._build_ui` 里的「使用帮助 / 打开 PDF / 命令」三个按钮创建后**未加入任何布局**
  （功能均由快捷键与命令面板覆盖），属于死 UI，可直接删除或接上工具栏
- 无文本层，因此没有搜索/选中复制；有文本层的数字版 PDF 也尚未利用 `get_text`
- 书签面板不支持输入过滤；几百上千条目录的书只能滚动查找
- 连续滚动（长图模式）、双页对开、笔记/标记导出现在都没有，只有页码级进度

## 本地集成

若把本包放在某个上层目录中，可由该目录的 `launcher.py` 统一查看/暂停/重启
（`launcher.py` 里把 `pdf_reader/reader.py` 登记为目标脚本）。
`_backup/` 是改造前的时间戳备份，已被 gitignore，可以随时删除。
