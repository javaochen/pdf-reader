## 截取模式（核心用法）

按 `Ctrl+S` 进入。截取模式的定位是**给"截一段去问 AI"用**：输出无损、可跨页、结果直接进剪贴板。

1. `Ctrl+S` 进入（鼠标移动时显示绿色虚线预览线）
2. 移动鼠标定位 → 回车确定**起始线**（红线）
3. 再移动 → 回车确定**结束线**（蓝线）→ 立即截取并复制到剪贴板
4. 分割线自动清空，可直接开始下一次；**再次按 `Ctrl+S` 才退出**
5. `Esc` 只撤销分割线（先撤结束线、再撤起始线），不会退出截取模式

几个要点：

| 行为 | 说明 |
|---|---|
| 跨页截取 | 起始线与结束线在不同页时自动纵向拼接；中转页会按需计算内容框，**不要求你先把那些页翻一遍** |
| 输出分辨率 | 目标 300 DPI，但**不超过该页内嵌图的真实分辨率**（扫描件不会被插值放大）；跨页时取各页最小值。状态栏会写明实际 DPI，例如"原生 108 DPI（低清扫描限幅）" |
| 上限保护 | 单次最多 50 页、2 亿像素；超限会在状态栏提示而不是拼出 GB 级位图 |
| 跳页后仍可用 | 回车确认是**窗口级快捷键**，跳页对话框（`Ctrl+I`）关闭后即使键盘焦点丢失也照常生效；换页会清掉上一页残留的预览线 |
| 与外部截图工具的分工 | 这里只做横线截取（两条水平线，整行宽度）。任意矩形框选、贴图标注交给 PixPin 之类工具 |

> 截取只渲染目标区域（PyMuPDF `clip`），且产物**不写入页面缓存**，所以连续截很多张也不会把内存吃满。

## 速记栏

右侧面板（`Ctrl+N` 显示/隐藏）：看书时随手记推导、疑问、反例，**停止输入约 0.8 秒自动保存**。

| 操作 | 说明 |
|---|---|
| 直接打字 | 输入即存，状态行显示「正在输入…」→「已保存 HH:MM:SS · 大小」 |
| **插入位置** | 在光标处插入一行 `--- 书名.pdf · 第 N 页 · 2026-09-28 21:40 ---`，以后好回溯原文 |
| **打开文件** | 用系统默认程序打开该 md（想看渲染效果就用 Typora/VSCode 打开） |
| 关闭程序 | 未到防抖时间的改动会在关窗时补齐，**不会丢字** |

- 默认写入程序目录下的 **`notes.md`**（单文件、纯 markdown 源码）；想换路径用配置 `notes_file`，
  相对路径按程序目录解析，也可以给绝对路径
- 保存用「临时文件 + 原子替换」，中途崩溃不会把原文件截断成半截
- 文件超过 2 MB 时只载入前一部分并在状态行说明（避免误指到大文件时卡住界面）
- 写不进去（比如程序目录只读）会在状态行标红提示，不会静默失败

> 这一版**刻意只做单文件 + 纯源码**：先确认这个面板在日常阅读里真的用得上，
> 再考虑多速记文件（按书/按章拆分）或公式渲染。

## 快捷键

| 按键 | 功能 |
|---|---|
| ← / → | 上一页 / 下一页 |
| Home / End | 首页 / 末页 |
| ↑ / ↓ | 上一书签 / 下一书签 |
| 回车 / 小键盘回车 | 截取、遮挡模式：确认当前分割线 |
| `Ctrl+S` | **截取模式**（进入后循环截取，再次按下退出） |
| `Ctrl+D` | 遮挡模式（`Esc` 退出） |
| `Ctrl+N` | 显示/隐藏右侧速记栏 |
| `Esc` | 撤销截取分割线（不退出截取模式）/ 退出遮挡模式 |
| `Ctrl+0` / `Ctrl+1` / `Ctrl+2` | 适合页面 / 适合宽度 / 原始大小（100%） |
| `Ctrl+=` / `Ctrl+-` | 放大 / 缩小 |
| `Ctrl+O` | 快速切换 PDF（按文件名筛选，最近打开优先） |
| `Ctrl+I` | 跳页（输入页码） |
| `Ctrl+P` | 命令面板（所有功能都在这，忘了快捷键就用它） |
| `Ctrl+Shift+C` / `Ctrl+Shift+B` | 复制当前 PDF 路径 / 复制书签到剪贴板 |
| `Ctrl+Shift+R` | 开关自动裁剪渲染（去白边） |
| `F5` | 重新扫描 PDF 目录 |
| `Ctrl+/` | 快捷键列表 |

> 注意 `Ctrl+O`（字母 O，快速切换）和 `Ctrl+0`（数字 0，适合页面）容易看混，按错时看一眼状态栏的模式提示。

## 阅读姿态

扫描版数学书的页面往往比屏幕大得多（实测某些书 fit 缩放只有 0.19），所以有三种模式：

| 模式 | 快捷键 | 适用场景 |
|---|---|---|
| **适合页面** | `Ctrl+0` | 先看清整页结构、找定理位置 |
| **适合宽度** | `Ctrl+1` | **主要阅读姿势**：宽度铺满窗口，高度超出时上下滚动 |
| **原始大小** | `Ctrl+2` | 核对排版细节 |

页面比视口大时，右侧/底部会出现滚动条（页面完整可达），也可以用左键拖拽平移。

## 书签与阅读进度

- 左侧是书签目录面板（来自 PDF 自带的 outline），点击即跳转
- `↑` / `↓` 按"当前页之前/之后的书签"跳转（不是目录里上下移动）
- `Ctrl+Shift+B` 把整本书签导出到剪贴板，可选格式：Markdown 标题（`#`/`##`）或无序列
- 阅读进度自动记录（每本书记住最后页码），下次打开自动恢复；写盘做了 500 ms 防抖，不再是每翻一页写一次

进度文件保存在 `state_dir`（默认与 PDF 目录相同）：

```
.pdf_reader_history.json     # 每本书最后页码
.pdf_reader_recent.json      # 最近打开顺序（快速切换按它排序）
```

## 遮挡模式

`Ctrl+D` 进入：光标下方区域涂成纯色（用来遮住答案、例题结果），回车确认/取消遮挡线，`Esc` 退出。
与截取模式互斥，进入一个会自动退出另一个。

## 配置详解

配置优先级：**`reader_config.json`（与 `reader.py` 同目录）> 环境变量 > 默认值**。

| 键 | 环境变量 | 默认值 | 说明 |
|---|---|---|---|
| `pdf_root_dir` | `PDF_READER_PDF_ROOT_DIR` | 系统「下载」文件夹 | 启动时扫描/打开的 PDF 目录 |
| `state_dir` | `PDF_READER_STATE_DIR` | 同 `pdf_root_dir` | 进度、最近记录的存放目录 |
| `notes_file` | `PDF_READER_NOTES_FILE` | `notes.md`（程序目录） | 速记文件；相对路径按程序目录解析 |
| `initial_pdf_keyword` | `PDF_READER_INITIAL_PDF_KEYWORD` | 空 | 启动时按文件名关键字自动打开某本 |
| `initial_page` | `PDF_READER_INITIAL_PAGE` | `1` | 无历史记录时的起始页 |

**默认目录怎么来的**（所以仓库里没有任何机器路径）：

1. Windows：读注册表 `User Shell Folders` 里系统认定的「下载」文件夹——即使用户在资源管理器里
   把「下载」移动到别的盘，这里也是权威位置；
2. 退回 `~/Downloads`；
3. 再退回 `~/Documents` → 用户主目录。

想固定到某个书库目录（顺便把速记放到书库旁边），例如：

```json
{
  "pdf_root_dir": "D:/Books",
  "state_dir": "D:/Books/.reader-state",
  "notes_file": "D:/Books/读书笔记.md"
}
```

日志：`PDF_READER_LOG=DEBUG` 会输出被捕获异常的完整堆栈（默认只输出 warning 以上）。
其余性能常量（缓存上限、DPI、防抖时长等）在 `reader.py` 顶部集中定义，注释里写了取值理由。

## 常见问题

**Q：按回车没反应？**
先移动鼠标——预览线必须先出现（绿色虚线）才有位置可确认。若你在截取模式下跳了页，旧预览线会被清空，
状态栏会提示"请先把鼠标移到页面上定位分割线"。

**Q：截出来的图太大 / 上传给 AI 太慢？**
输出会按该页原图分辨率封顶，正常情况下不会虚高；如果一本书的原生分辨率本身很高（比如 4.17 px/pt），
截大范围时图仍然可观——把两条线拉近一些即可。跨页拼接会明显增大体积。

**Q：文字看不清 / 页面太小？**
`Ctrl+1` 适合宽度 + 拖拽平移。若页面有白边，开 `Ctrl+Shift+R` 自动去白边会让字变大（对灰底扫描件同样生效）。

**Q：打开很慢？**
启动时会递归扫描 `pdf_root_dir`。把 `pdf_root_dir` 指向专门的书籍目录（而不是整个下载目录）会快很多。
打开超大扫描件（几百 MB、上千页）时首页渲染需要一点时间，属正常。

**Q：进度/最近记录不见了？**
它们存在 `state_dir`。若你换了 `pdf_root_dir` 而没设 `state_dir`，默认目录随之改变，旧记录看起来就"丢了"——
用配置把 `state_dir` 固定回原处即可。

**Q：速记存在哪？会不会被我误提交到 git？**
默认是程序目录下的 `notes.md`，而且 `.gitignore` 里已经排除（连同 `notes_local.md`、`*.notes.md`），
不会被提交。想换位置用配置 `notes_file`，例如指向书库目录或同步盘。

**Q：速记为什么不渲染公式？**
这一版刻意做成"单文件 + markdown 源码"，先把"输入不再丢、位置能回溯"做扎实；
渲染或按书拆分等需求，等确认这个面板真正常用之后再考虑。

**Q：为什么不能框选截取？**
内置模式专做外部截图工具做不到的三件事：**原生分辨率无损输出、跨页拼接、不受屏幕缩放影响**。
任意矩形框选请用 PixPin 之类工具，两者互补。
